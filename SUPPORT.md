# Support

GradeWise is a free, solo-maintained open-source project — there is no dedicated support team, live chat, or
SLA. Here's the best way to get help depending on what you need.

## Before opening anything

Check whether your question is already answered:

- **[/methodology](https://d-majumder.github.io/gradewise/methodology)** — how conversion formulas are verified
  and labeled (official vs. unverified vs. custom)
- **[README.md](./README.md)** — features, architecture, local setup, how to add an institution or formula
- **[/privacy](https://d-majumder.github.io/gradewise/privacy)** — what data GradeWise does and doesn't collect

## I found a reproducible bug

Open a [bug report issue](../../issues/new?template=bug_report.md) using the bug report template. Include steps
to reproduce, what you expected, and what actually happened.

## A university's conversion formula looks wrong, outdated, or is missing

This is the most valuable kind of report for this project. Open a
[formula correction issue](../../issues/new?template=formula_correction.md) if an existing formula is wrong, or
a [university request issue](../../issues/new?template=university_request.md) if your institution isn't listed
at all. Please read the "Academic formula / university data contributions" section of
[CONTRIBUTING.md](./CONTRIBUTING.md) first — a correction backed by an official source is the fastest to act on.

## I have an idea for a new feature or improvement

Open a [feature request issue](../../issues/new?template=feature_request.md). For anything substantial, this is
also the right first step before writing code — see the "Issue-first guidance" section of
[CONTRIBUTING.md](./CONTRIBUTING.md).

## I found a security vulnerability

Please **do not** open a public issue — see [SECURITY.md](./SECURITY.md) for private reporting instructions.

## I want to contribute code or data

Start with [CONTRIBUTING.md](./CONTRIBUTING.md).

## None of the above fits

Open a plain GitHub issue describing what you need — a maintainer (there's currently one:
[@D-Majumder](https://github.com/D-Majumder)) will read it when they can, but again, there's no guaranteed
response time for a project run in someone's spare time.
